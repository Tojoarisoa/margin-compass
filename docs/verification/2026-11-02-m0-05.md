## Details

### VER-01: AWS account plans — Verified
- New accounts choose a **Free plan** or a **Paid plan**. Free plan: up to $200 credits; the account closes after 6 months or when credits run out; access is limited to select services. Paid plan: all services, billed beyond credits; new Paid customers are also eligible for up to $200 credits. Bedrock AgentCore is Paid-plan only. ([AWS Free Tier](https://aws.amazon.com/free/))
- Joining AWS Organizations ends Free Tier credits immediately (Secondary: [AWS Free Tier FAQs](https://aws.amazon.com/free/faqs/) via search summary).
- **Decision input:** create the fresh account on the **Paid plan** (PLAN.md §11.1 already assumes it). Don't join an Organization.

### VER-03: S3 Vectors — Verified
- Available in us-east-1, eu-west-1, eu-west-3, and others. ([Regions and quotas](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors-regions-quotas.html))
- Limits: 1–4,096 dimensions; up to 2B vectors per index; 10,000 indexes per bucket; 40 KB metadata per vector, of which 2 KB filterable; up to 50 metadata keys; top-K up to 10,000; 500 vectors per PutVectors call. ([Limitations](https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors-limitations.html))
- Pricing (us-east-1): $0.06/GB-month storage; $0.20/GB PUT (128 KB minimum per PUT); $2.50 per million queries plus $0.004/TB processed for the first 100K vectors; first 512 KB returned per query free. ([S3 pricing](https://aws.amazon.com/s3/pricing/), rates from AWS's worked examples)
- Generally available. ([AWS China blog](https://aws.amazon.com/cn/blogs/china/amazon-s3-vectors-now-generally-available-with-increased-scale-and-performance))
- No keyword search was found in the docs, so the in-Lambda BM25 for hybrid retrieval stays.

### VER-05: Bedrock — Verified except prices
- **Model IDs** (GA, from the Bedrock prompt-caching table): `anthropic.claude-haiku-5-5`, `anthropic.claude-sonnet-5-5`, `anthropic.claude-haiku-4-5-20251001-v1:0`, `amazon.nova-micro-v1:0`, `amazon.nova-lite-v1:0`, `amazon.nova-2-lite-v1:0`. ([Prompt caching](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html))
- **Prompt caching:** minimum prefix per checkpoint is 512 tokens for Claude Haiku/Sonnet 5.5, 4,096 for Claude Haiku 4.5, and 1K for Nova; TTL 5 minutes (1 hour for Claude 4.5+); cache reads billed at a lower rate; writes may cost more than input. **Not supported with batch inference.**
- **Batch:** 50% lower than on-demand for select models. ([Bedrock pricing](https://aws.amazon.com/bedrock/pricing/))
- **Embeddings:** Titan Text Embeddings V2, `amazon.titan-embed-text-v2:0`, 8,192 tokens in, 1,024 / 512 / 256 dimensions. ([Titan embeddings](https://docs.aws.amazon.com/bedrock/latest/userguide/titan-embedding-models.html))
- **Prices — Open.** The official pricing page doesn't expose its price tables to automated reading. Secondary figures (per 1M tokens): Nova Micro $0.035 in / $0.14 out; Nova Lite $0.06 / $0.24; Claude Haiku 4.5 $1 / $5. The page does state that Claude Sonnet 5.5 cache-read pricing fell 50% from 2026-10-07. **Action:** the owner reads the prices from the Bedrock console or the AWS Pricing Calculator and records them in ADR-003 before M1-06. Until then the code-level budget caps (§8.7) bound the spend.
- HIPAA: Bedrock is HIPAA-eligible (ADR-017). Not needed by Margin Compass itself.

### VER-06: AWS Budgets — Verified
- Monitoring and alerts are free. The first **two action-enabled budgets** are free; each additional one is $0.10/day. ([Budgets pricing](https://aws.amazon.com/aws-cost-management/aws-budgets/pricing/))
- Action types: apply an **IAM policy**, apply an **SCP**, or target running **EC2/RDS** instances. IAM and SCP actions reset each budget period. ([Announcement](https://aws.amazon.com/about-aws/whats-new/2020/10/announcing-aws-budgets-actions/))
- Billing data is refreshed **at least once per day**, and alerts follow that cadence. ([Budgets best practices](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-best-practices.md))
- **Effect:** the kill switch is an IAM deny policy (Bedrock invoke, scheduler, and Lambda URL roles) applied by a budget action. It can lag real spend by a day or more, so the per-question, daily, and monthly caps in code (AGENTS.md rule 6) remain the first line of defense. Observing actual refresh latency needs the account (M0-07).

### VER-07: Lambda response streaming — Verified
- Native streaming is **Node.js only**. Python needs a custom runtime or the **Lambda Web Adapter**. Streams up to 200 MB; first 6 MB uncapped, then 2 MBps. Function URLs support streaming. ([Response streaming](https://docs.aws.amazon.com/lambda/latest/dg/configuration-response-streaming.html))

### VER-08: CloudFront OAC for Lambda function URLs — Verified, streaming Open
- The function URL must use `AWS_IAM` auth. For PUT/POST, the **client must compute the SHA-256 of the body and send it as `x-amz-content-sha256`**; Lambda doesn't accept unsigned payloads. ([CloudFront OAC for Lambda](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/private-content-restricting-access-to-lambda.html))
- **Effect:** the dashboard's agent client hashes each request body (Web Crypto `SubtleCrypto.digest`). Whether streamed responses pass through an OAC-signed CloudFront origin end to end is **Open**; spike in M1-07, with the polling fallback (ADR-012) kept.

### VER-09: LangGraph DynamoDB checkpointer — Verified
- `langgraph-checkpoint-aws` 1.2.6 (2026-10-23), MIT, Python ≥ 3.10, published by the LangChain org. Provides `DynamoDBSaver` with TTL, gzip compression, and S3 offload for checkpoints over 350 KB. ([PyPI](https://pypi.org/project/langgraph-checkpoint-aws/), [AWS guide](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/ddb-langgraph-checkpoint.html))
- AWS's example table uses on-demand billing, but the saver also works with provisioned capacity; AWS documents `ProvisionedThroughputExceededException` handling. **Effect:** keep provisioned mode (ADR-011) with adaptive retries; enable TTL, compression, and S3 offload.

### VER-11: DuckDB-WASM — Partly verified
- Variants: `mvp`, `eh`, and threaded `coi` (needs cross-origin isolation). ([Instantiation](https://duckdb.org/docs/current/clients/wasm/instantiation))
- `httpfs` in WASM is a JavaScript reimplementation that "does not support all use cases"; remote reads need CORS when cross-origin, and requests are upgraded to HTTPS. ([WASM extensions](https://duckdb.org/docs/2.0/clients/wasm/extensions.html))
- **Supply-chain finding:** `@duckdb/duckdb-wasm` **1.29.2** was a malicious release in the September 2025 npm compromise (CVE-2025-59037, MAL-2025-46991). ([OSV](https://osv.dev/vulnerability/MAL-2025-46991), [GitLab advisory](https://advisories.gitlab.com/npm/duckdb/CVE-2025-59037/))
- **Open:** wasm bundle size and Parquet HTTP range reads through CloudFront. Measure in a spike at M1-07.
- **Effect:** pin an exact, advisory-free version with a committed lockfile and `npm ci`; serve the wasm bundles from our own CloudFront (same origin, so no CORS and no third-party CDN at runtime); add a dependency audit to CI.

### VER-12: dbt-duckdb in Lambda — Verified limits, Secondary pattern
- Lambda: up to 10,240 MB memory, 15 min timeout, `/tmp` 512–10,240 MB, container images up to 10 GB. **New accounts have reduced concurrency and memory quotas**, raised automatically with usage. ([Lambda quotas](https://docs.aws.amazon.com/lambda/latest/dg/gettingstarted-limits.html))
- DuckDB reads S3 Parquet via `httpfs` with a credential-chain secret; dbt-duckdb can use `/tmp/dbt.duckdb`. (Secondary: [DuckDB S3 import](https://duckdb.org/docs/lts/guides/network_cloud_storage/s3_import.html), [dbt-duckdb README](https://github.com/amiller-gh/dbt-duckdb))
- **Effect:** container image (ADR-004 holds). In M0-07, check the account's Lambda memory quota in Service Quotas; §7.5 needs up to 6 GB. Bundle extensions into the image so nothing is downloaded at runtime.

([client-inference.md](https://github.com/open-telemetry/semantic-conventions-genai/blob/main/docs/gen-ai/client-inference.md), [gen-ai-spans.md](https://github.com/open-telemetry/semantic-conventions-genai/blob/main/docs/gen-ai/gen-ai-spans.md))
